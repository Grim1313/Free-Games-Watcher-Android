# Free Games Watcher для Android

[English](README.md)

Приложение ищет временные раздачи игр для ПК в Steam, Epic Games Store и GOG. Для каждой раздачи есть ссылка на страницу магазина и срок окончания, если он известен. Поддерживаются Android 8.0 и новее, русский и английский языки.

## Использование

Нажмите **значок обновления**, чтобы обновить раздачи для выбранной страны. Вкладка **«Раздачи»** показывает подтверждённые акции. Во вкладке **«Скоро»** видны анонсы Epic и GOG с датой начала. Игра попадёт в активную ленту, когда магазин подтвердит старт акции. Результат, время и число запросов последней проверки по каждому магазину доступны в диагностике источников. Если у игры нет оценки Epic, включите **Записывать журнал проверок**, запустите проверку на этом экране и нажмите **Сохранить журнал (.txt)**. По умолчанию запись выключена.

Раздачи сгруппированы по магазинам. Нажмите на заголовок магазина, чтобы свернуть или развернуть его список. Нажмите на название игры для просмотра подробностей или зелёную кнопку для перехода в магазин. В карточках доступны обычная цена, доля положительных отзывов Steam, оценки игроков Epic и GOG по пятибалльной шкале, количество отзывов, жанры и поддерживаемые платформы, если магазин передал эти данные. Игры можно искать по названию или ID, выбирать по магазину и сортировать внутри каждого магазина по окончанию, дате обнаружения, рейтингу Steam или названию. Доступны системная, светлая и чёрная OLED-тема. Язык интерфейса и страна каталога выбираются отдельно.

- **Личные отметки.** Игру можно отметить как полученную, игнорировать до восстановления, скрыть на время текущей акции или отложить на 24 часа. Действие можно отменить сразу или позднее снять отметку в настройках. Раздачи можно отметить прочитанными по одной или сразу все.
- **Настройки и справка.** Поиск по настройкам помогает найти фильтры, уведомления, фоновые проверки, оформление, отметки, резервные копии, историю и диагностику. В справке есть пояснения к значкам на карточках.
- **Фильтры.** Можно выбрать типы контента, жанры и операционные системы, исключить названия по ключевым словам или Steam ID, задать минимум отзывов Steam и долю положительных оценок. Для отбора по жанру или платформе нужны соответствующие данные магазина. DLC, саундтреки, инструменты и демоверсии по умолчанию скрыты.
- **История и перенос.** Сохранённые раздачи доступны для поиска офлайн. В настройках можно задать срок хранения истории и экспортировать настройки и отметки в JSON с историей или без неё. Приложение принимает резервные копии браузерного расширения. Перед импортом видны страна и количество отметок и записей. Для переноса скрытия конкретной акции включите историю. Восстановленные раздачи появляются в активной ленте после проверки в магазине.
- **Оповещения.** По умолчанию приложение проверяет магазины каждые три часа. Доступны интервалы от 15 минут до 24 часов. Android может отложить запуск. Можно настроить тихие часы, повторы оповещений и напоминания за 1–72 часа до известного срока окончания. На новой установке окно напоминаний составляет три часа, при обновлении сохраняется выбранное ранее значение. Пауза отключает проверки и запоминает выбор магазинов.

## Источники данных и приватность

Steam использует два поиска, резервную витрину и региональные варианты покупки StoreBrowse. Epic использует недельную ленту и каталог Browse. Оценку игроков приложение запрашивает у API рейтингов Epic. Если оценки нет, приложение запрашивает её у стороннего сервиса EGData по идентификатору предложения. При неполном ответе Browse сервис также получает страну и параметры поиска. В обоих случаях EGData видит IP-адрес. GOG проверяется по публичным разделам главной и каталогу. Если в старой записи сохранилась только ссылка на главную, при открытии приложение запрашивает у GOG страницу игры по её ID. Скриншоты или иллюстрации магазина загружаются при показе карточек. Настройки, история и отметки хранятся на устройстве.

## Сборка из исходников

Откройте корень проекта в Android Studio с установленными Android SDK 37 и Build Tools 36.0.0. Для запуска из PowerShell укажите в текущем сеансе пути к JDK и SDK своей установки. Для стандартных путей Android Studio на Windows подойдут следующие команды.

```powershell
$env:JAVA_HOME = "$env:ProgramFiles\Android\Android Studio\jbr"
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
& "$env:ANDROID_HOME\platform-tools\adb.exe" -e install -r app\build\outputs\apk\debug\app-debug.apk
```

Инструментальные тесты запускаются командой `.\gradlew.bat :app:connectedDebugAndroidTest` при подключённом тестовом устройстве. Устанавливаемый пакет для разработки — `bz.fgw.android.debug`, минимальная версия — Android 8.0.
